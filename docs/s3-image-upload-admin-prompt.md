# S3 이미지 업로드 어드민 프론트엔드 개발 프롬프트

## 개요
어드민 패널에서 상점 등록/수정 시 이미지를 S3에 업로드하고 관리하는 UI를 구현합니다.

## 요구사항

### 1. 이미지 업로드 컴포넌트
- 드래그 앤 드롭 이미지 업로드
- 클릭하여 파일 선택 기능
- 이미지 미리보기 기능
- 업로드 진행률 표시
- 지원 형식 안내 (JPG, PNG, WebP)
- 파일 크기 제한 안내 (최대 5MB)

### 2. 대표 이미지 관리
- 단일 이미지 업로드/교체
- 기존 이미지 삭제 기능
- 이미지 크롭/리사이징 도구 (선택사항)
- 업로드 전 이미지 미리보기

### 3. 추가 이미지 갤러리
- 다중 이미지 업로드 (최대 5장)
- 이미지 순서 변경 (드래그 앤 드롭)
- 개별 이미지 삭제
- 이미지 확대 보기 모달

### 4. 상점 등록/수정 폼 통합
- 기존 상점 등록 폼에 이미지 업로드 섹션 추가
- 폼 검증 시 이미지 업로드 상태 확인
- 저장 시 이미지와 상점 정보 동기화

### 5. 이미지 상태 관리
- 업로드 중, 완료, 실패 상태 표시
- 업로드 실패 시 재시도 기능
- 임시 저장된 이미지 관리

### 6. UX/UI 개선사항
- 로딩 스피너 및 진행률 표시
- 성공/실패 토스트 메시지
- 이미지 최적화 안내 툴팁
- 반응형 디자인 (모바일 대응)

### 7. 에러 처리
- 파일 형식 오류 메시지
- 파일 크기 초과 메시지
- 네트워크 오류 처리
- 서버 오류 처리

### 8. 성능 최적화
- 이미지 lazy loading
- 썸네일 생성 및 표시
- 이미지 압축 (클라이언트 사이드)
- 캐싱 전략

## 구현 순서
1. 이미지 업로드 컴포넌트 개발
2. 파일 검증 및 미리보기 기능
3. S3 업로드 API 연동
4. 상점 폼에 이미지 섹션 통합
5. 이미지 갤러리 및 관리 기능
6. 에러 처리 및 사용자 피드백
7. 성능 최적화 및 UX 개선
8. 테스트 및 문서화

## 기술 스택 제안
- React/Vue.js 파일 업로드 라이브러리
- 이미지 크롭: react-image-crop 또는 vue-cropperjs
- 드래그 앤 드롭: react-dropzone 또는 vue-dropzone
- 이미지 압축: browser-image-compression
- 진행률 표시: 커스텀 프로그레스 바

## UI/UX 가이드라인
- 직관적인 드래그 앤 드롭 영역
- 명확한 업로드 상태 표시
- 일관된 에러 메시지 스타일
- 접근성 고려 (alt 텍스트, 키보드 네비게이션)
- 모바일 친화적 터치 인터페이스

## 참고사항
- 기존 어드민 디자인 시스템과 일관성 유지
- 다국어 지원 고려
- 브라우저 호환성 확인
- 이미지 메타데이터 보존 여부 결정
