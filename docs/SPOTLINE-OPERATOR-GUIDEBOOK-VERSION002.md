## 1. SpotLine 시스템 개요

### 🎯 SpotLine의 목적

SpotLine은 **현재 장소를 기준으로 다음 경험을 자연스럽게 제안**하는 서비스입니다.

**SpotLine은 다음이 아닙니다:**

- ❌ 광고 플랫폼
- ❌ 리뷰 서비스
- ❌ 사용자 참여형 커뮤니티

**SpotLine의 핵심 가치:**

- ✅ 자연스러운 경험 흐름 제안
- ✅ 사용자 이동 패턴 관찰
- ✅ 큐레이션의 신뢰성 구축

### 🔄 VERSION002 주요 변화

#### 새로운 기능

1. **체험 설정 시스템**: "SpotLine 체험하기" 버튼의 동작을 관리자가 설정
2. **실시간 통계**: 각 체험 설정의 사용 현황 모니터링
3. **미리보기 기능**: 설정 변경 전 결과 확인 가능
4. **표준화된 관리**: 통일된 관리자 계정과 QR 코드 체계

#### 개선된 기능

- 더 정확한 사용자 분석 데이터
- 향상된 매장 관리 인터페이스
- 실시간 설정 변경 반영

## 3. 체험 설정 관리

### 🎯 체험 설정이란?

사용자가 "SpotLine 체험하기" 버튼을 클릭했을 때 **어떤 매장으로 안내할지 결정하는 규칙**입니다.

### 체험 설정 타입

#### 1. 랜덤 선택 (Random)

- **설명**: 등록된 모든 매장 중 무작위로 선택
- **사용 시기**: 기본 설정, 다양한 체험 제공 시
- **설정 방법**: 추가 설정 불필요
- **예시**: 매번 다른 매장으로 안내

#### 2. 고정 매장 (Fixed)

- **설명**: 항상 특정 매장으로 안내
- **사용 시기**: 특별 이벤트, 신규 매장 홍보 시
- **설정 방법**: 고정할 매장의 QR 코드 ID 선택
- **예시**: 항상 "카페 스팟라인"으로 안내

#### 3. 지역 기반 (Area Based)

- **설명**: 선택한 지역의 매장들 중에서만 선택
- **사용 시기**: 특정 지역 집중 홍보 시
- **설정 방법**: 포함할 지역들 선택
- **예시**: 강남 지역 매장들만 선택

#### 4. 가중치 기반 (Weighted)

- **설명**: 매장별로 다른 확률로 선택
- **사용 시기**: 인기 매장 우선 노출, 균형 조정 시
- **설정 방법**: 각 매장에 가중치 부여
- **예시**: 카페 50%, 갤러리 30%, 레코드샵 20%

### 체험 설정 생성 단계별 가이드

#### Step 1: 새 설정 생성

1. 관리자 대시보드 → "체험 설정 관리"
2. "새 설정 추가" 버튼 클릭
3. 기본 정보 입력:
   - **설정 이름**: 구분하기 쉬운 이름 (예: "강남 집중 체험")
   - **설명**: 설정의 목적과 내용 (예: "강남 지역 매장만 선택하는 체험")
   - **우선순위**: 숫자가 낮을수록 높은 우선순위

#### Step 2: 체험 타입 선택 및 설정

```
랜덤 선택을 선택한 경우:
→ 추가 설정 없음

고정 매장을 선택한 경우:
→ 드롭다운에서 고정할 매장 선택

지역 기반을 선택한 경우:
→ 체크박스에서 포함할 지역들 선택
   ☑ 강남역  ☑ 논현동  ☐ 신사동  ☑ 홍대입구

가중치 기반을 선택한 경우:
→ 각 매장별 가중치 입력
   카페 스팟라인: 50
   바이닐 카페: 30
   북카페 리딩룸: 20
```

#### Step 3: 미리보기 및 테스트

1. "미리보기" 버튼 클릭
2. 테스트 횟수 설정 (기본 10회)
3. 결과 확인:
   - 각 매장별 선택 횟수
   - 선택 비율
   - 예상 사용자 경험

#### Step 4: 설정 활성화

1. 설정 저장
2. 필요시 "기본 설정으로 지정"
3. 실시간 적용 확인

### 기본 설정 관리

- **기본 설정**: 사용자가 체험할 때 기본적으로 적용되는 설정
- **변경 방법**: 원하는 설정에서 "기본 설정으로 지정" 클릭
- **즉시 반영**: 변경 즉시 모든 사용자에게 적용

## 4. 매장 관리

### 🏪 등록된 매장 현황 (VERSION002 기준)

#### 강남 지역 (5개)

| QR 코드 ID            | 매장명           | 위치   | 카테고리 |
| --------------------- | ---------------- | ------ | -------- |
| `cafe_gangnam_001`    | 카페 스팟라인    | 강남역 | 카페     |
| `dessert_gangnam_001` | 디저트 하우스    | 강남역 | 카페     |
| `culture_gangnam_001` | 북카페 리딩룸    | 강남역 | 문화     |
| `gallery_gangnam_001` | 아트 갤러리 모던 | 논현동 | 문화     |
| `brunch_gangnam_001`  | 브런치 스팟      | 신사동 | 레스토랑 |

#### 홍대 지역 (3개)

| QR 코드 ID           | 매장명             | 위치     | 카테고리 |
| -------------------- | ------------------ | -------- | -------- |
| `cafe_hongdae_001`   | 바이닐 카페        | 홍대입구 | 카페     |
| `food_hongdae_001`   | 스트리트 푸드 마켓 | 홍대입구 | 레스토랑 |
| `record_hongdae_001` | 인디 레코드샵      | 홍대입구 | 소매     |

### 새 매장 등록 절차

#### Step 1: 기본 정보 입력

```
매장명: [필수] 예) "새로운 북카페"
카테고리: [필수] cafe/restaurant/culture/retail 중 선택
주소: [필수] 예) "서울시 마포구 홍익로 123"
지역: [필수] 예) "홍대입구"
```

#### Step 2: QR 코드 ID 생성

- **형식**: `{카테고리}_{지역}_{순번}`
- **예시**: `cafe_hongdae_002`
- **주의**: 기존 ID와 중복되지 않도록 확인

#### Step 3: SpotLine 정보 입력

```
한 문장 설명: [필수] 100자 이내
예) "조용한 분위기에서 책과 함께하는 시간"

대표 이미지: [필수] 1장만
- 권장 크기: 1200x800px
- 형식: JPG, PNG

SpotLine 스토리: [선택] 500자 이내
예) "이 장소가 SpotLine에 포함된 이유는..."
```

#### Step 4: 외부 링크 설정

```
Instagram: https://instagram.com/매장계정
웹사이트: https://매장웹사이트.com
블로그: https://blog.naver.com/매장블로그
Notion: https://notion.so/매장페이지
```

### 매장 정보 수정

1. 매장 목록에서 수정할 매장 선택
2. "편집" 버튼 클릭
3. 필요한 정보 수정
4. "저장" 버튼으로 변경사항 적용

### 매장 비활성화

- **목적**: 임시 휴업, 폐점 등
- **방법**: 매장 편집 → "활성 상태" 체크 해제
- **효과**: 체험 설정에서 자동 제외

## 7. 문제 해결

### 🚨 긴급 상황 대응

#### 서버 다운

1. **즉시 확인사항**

   - 서버 상태 점검
   - 데이터베이스 연결 확인
   - 네트워크 상태 점검

2. **복구 절차**

   ```bash
   # 서버 재시작
   pnpm dev

   # 데이터베이스 연결 테스트
   pnpm run test:db

   # 시스템 상태 확인
   curl http://localhost:4000/api/stores
   ```

3. **사용자 안내**
   - 임시 점검 안내
   - 예상 복구 시간 공지
   - 대안 서비스 제공

#### 체험 설정 오류

1. **증상**: 사용자가 체험하기 클릭 시 오류 발생
2. **확인사항**:

   - 기본 설정 활성화 여부
   - 설정된 매장들의 활성 상태
   - QR 코드 ID 유효성

3. **해결방법**:
   - 기본 설정을 "랜덤 선택"으로 변경
   - 비활성화된 매장 제외
   - 설정 재저장

### 🔧 일반적인 문제 해결

#### 매장이 체험에서 선택되지 않음

**원인**: 매장이 비활성화되었거나 체험 설정에서 제외됨
**해결**:

1. 매장 활성 상태 확인
2. 체험 설정에 해당 매장 포함 여부 확인
3. QR 코드 ID 정확성 확인

#### 사용자가 404 오류 페이지 접속

**원인**: 잘못된 QR 코드 ID 사용
**해결**:

1. QR 코드 ID 형식 확인 (`cafe_gangnam_001` 형태)
2. 데이터베이스에 해당 ID 존재 여부 확인
3. 프론트엔드에서 올바른 ID 사용하도록 수정

#### 체험 설정 변경이 반영되지 않음

**원인**: 캐시 문제 또는 설정 저장 오류
**해결**:

1. 브라우저 캐시 삭제
2. 설정 재저장
3. 서버 재시작 (필요시)

## 📈 성공 지표

### KPI (핵심 성과 지표)

- **일일 체험 횟수**: 목표 100회/일
- **매장별 균등 분배**: 편차 ±20% 이내
