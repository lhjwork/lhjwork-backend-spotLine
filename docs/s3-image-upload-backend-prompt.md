# S3 이미지 업로드 백엔드 개발 프롬프트

## 개요
상점 등록 시 실제 이미지를 S3에 업로드하고, GET 요청 시 S3에서 이미지를 제공하는 기능을 구현합니다.

## 요구사항

### 1. 환경 설정
- AWS S3 버킷 연결을 위한 환경 변수 추가
- AWS SDK v3 설치 및 설정
- 이미지 업로드를 위한 multer 미들웨어 설정

### 2. S3 서비스 구현
- 이미지 업로드 함수 구현
- 이미지 삭제 함수 구현 (기존 이미지 교체 시)
- 이미지 URL 생성 함수 구현
- 지원 이미지 형식: JPG, PNG, WebP
- 최대 파일 크기: 5MB
- 이미지 리사이징 (선택사항): 최대 1920x1080

### 3. 스토어 모델 업데이트
- `representativeImage` 필드를 S3 키로 저장
- 기존 `images` 배열도 S3 키 배열로 변경
- 이미지 URL 가상 필드 추가 (getter)

### 4. API 엔드포인트 구현
- `POST /admin/stores/:id/image` - 대표 이미지 업로드
- `POST /admin/stores/:id/images` - 추가 이미지 업로드 (다중)
- `DELETE /admin/stores/:id/image` - 대표 이미지 삭제
- `DELETE /admin/stores/:id/images/:imageId` - 특정 이미지 삭제

### 5. 기존 API 수정
- 스토어 조회 시 이미지 URL 반환
- 스토어 생성/수정 시 이미지 처리 로직 추가

### 6. 에러 처리
- 파일 형식 검증
- 파일 크기 검증
- S3 업로드 실패 처리
- 존재하지 않는 이미지 삭제 시도 처리

### 7. 보안 고려사항
- 파일명 중복 방지 (UUID 사용)
- 악성 파일 업로드 방지
- 적절한 CORS 설정

## 구현 순서
1. 환경 변수 및 AWS SDK 설정
2. S3 서비스 유틸리티 함수 구현
3. 이미지 업로드 미들웨어 구현
4. 스토어 모델 업데이트
5. 이미지 관련 API 엔드포인트 구현
6. 기존 스토어 API 수정
7. 에러 처리 및 검증 로직 추가
8. 테스트 및 문서화

## 기술 스택
- AWS SDK v3 (@aws-sdk/client-s3)
- multer (파일 업로드)
- sharp (이미지 리사이징, 선택사항)
- uuid (고유 파일명 생성)

## 참고사항
- 기존 코드와의 호환성 유지
- 점진적 마이그레이션 고려 (기존 이미지 URL과 새 S3 이미지 동시 지원)
- 개발/프로덕션 환경별 S3 버킷 분리 고려
