# Spotline 사용자 여정 분석

## 핵심 사용자 시나리오

### 시나리오 1: 데이트 커플 (1차 타겟)
**상황**: 홍대 카페에서 커피 마시고 있는 커플
1. **Trigger**: "이제 어디 갈까?" 대화 시작
2. **Discovery**: 테이블 위 Spotline QR 발견
3. **Action**: QR 스캔 → 즉시 추천 페이지 로드
4. **Decision**: "홍대 근처 데이트 코스" 리스트 확인
5. **Conversion**: 추천 장소 지도 클릭 → 실제 이동

### 시나리오 2: 전시 관람 후 (문화 소비층)
**상황**: 성수동 갤러리 관람 후
1. **Context**: 전시 감상 후 여운을 이어갈 공간 필요
2. **Touch Point**: 갤러리 출구/카운터의 QR
3. **Content**: "전시 후 가기 좋은 곳" 큐레이션
4. **Options**: 북카페, 아트샵, 루프탑 바 등

### 시나리오 3: 비즈니스 미팅 후
**상황**: 강남 카페에서 미팅 종료
1. **Need**: 후속 미팅 장소 또는 개인 시간 활용
2. **Solution**: "미팅 후 추천" 카테고리
3. **Targeting**: 조용한 카페, 코워킹 스페이스, 식당

## 사용자 페르소나 세분화

### Primary: 액티브 로컬 탐험가 (25-35세)
- 새로운 장소 발견에 적극적
- SNS 공유 활발
- 계획보다 즉흥적 성향

### Secondary: 효율적 시간 활용자 (30-40세)
- 제한된 시간 내 최적 동선 선호
- 검증된 장소 선호
- 실용적 가치 중시

### Tertiary: 관광객/방문자
- 지역 정보 부족
- 현지인 추천 신뢰
- 특별한 경험 추구
